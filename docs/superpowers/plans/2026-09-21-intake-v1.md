# Intake v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Onboarding captures vitals, level, goal mode and current fitness (Strava-first); the plan builder uses them for paces, ramp and HR ranges; the coach opens with a full brief.

**Architecture:** A new pure module `src/lib/fitness.ts` (Riegel projection, training paces from a reference race, HR zones) feeds `buildPlan()`; five new columns on `profiles` and one on `goals` carry the answers; the coach edge function gains a cached "runner brief" and an `intro` mode. Screens stay the same four steps with extra fields, split into `src/features/onboarding/` pieces so route files stay thin.

**Tech Stack:** Expo SDK 57 / RN 0.86 / TypeScript strict · zustand · Supabase (Postgres, Deno edge functions) · Vitest (new) · Claude Sonnet 5 via raw HTTP in `coach`.

**Spec:** `docs/superpowers/specs/2026-09-21-intake-design.md` (read its Baseline section first).
